# Save your logo files in this folder

Save the two provided images here with these exact names so the site picks them up:

- `kraft-logo.png`  → the full "⚡ KRAFT" wordmark (used in the header and footer)
- `kraft-icon.png`  → the lightning-bolt hexagon icon only (used as the browser favicon / touch icon)

Tip: for the favicon, a square icon (e.g. 256×256 or 512×512) works best.
